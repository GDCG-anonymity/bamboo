# ○○에서 전해드립니다 — 익명 게시판 (대나무숲)

「괴담에 떨어져도 출근을 해야 하는구나」 2차 팬사이트용 익명 게시판입니다.
테마 3종(어둠탐사기록 / 백일몽 / 재난관리국)을 방문자가 직접 골라 볼 수 있습니다.

## 파일 구성
| 파일 | 역할 |
|---|---|
| index.html | 화면 뼈대 |
| style.css | 3개 테마 디자인 (맨 위 `[data-theme=...]` 색상 변수만 바꿔도 분위기 조정 가능) |
| app.js | 기능 전체. 맨 위 `THEMES` 안에 테마별 용어(글 번호, 익명 이름, 신고 버튼 등)가 모여 있음 |
| firebase-config.js | Firebase 연결 정보 + 관리자 이메일 |
| firestore.rules | 보안 규칙 (콘솔에 붙여넣기) |
| firestore.indexes.json | 필요한 복합 색인 2개 |
| logos/ | 테마별 로고(`테마.png`)와 탭 아이콘(`테마-icon.png`). 어둠탐사기록은 검은 헤더에 맞춰 흑백을 반전한 `dark-invert.png`를 씀 |

## Firebase 설정 순서
1. **새 프로젝트 생성** → 웹 앱 추가 → 나오는 설정값을 `firebase-config.js`에 붙여넣기
2. **Authentication > 로그인 방법**에서 두 개 사용 설정
   - **익명** (방문자용, 보이지 않게 자동 로그인)
   - **이메일/비밀번호** (관리자용)
3. **Authentication > 사용자 > 사용자 추가**: 이메일 `research1@bamboo.local` + 원하는 비밀번호
   - 이메일을 바꾸고 싶으면 `firebase-config.js`의 `ADMIN_EMAIL`과 `firestore.rules`의 `isAdmin()` 안 주소를 둘 다 똑같이 바꿔주세요.
4. **Firestore Database 만들기** (프로덕션 모드) → **규칙** 탭에 `firestore.rules` 내용 전체 붙여넣고 게시
5. **색인 2개 만들기** (Firestore > 색인 > 복합 > 색인 추가)
   - 컬렉션 `posts`: `hidden` 오름차순, `createdAt` 내림차순
   - 컬렉션 `comments`: `hidden` 오름차순, `createdAt` 오름차순
   - 또는 그냥 사이트를 열어보면 브라우저 콘솔(F12)에 색인 생성 링크가 뜨는데, 그걸 눌러도 됩니다. 만든 뒤 몇 분 기다려야 적용돼요.
6. **Authentication > 설정 > 승인된 도메인**에 `아이디.github.io` 추가
7. GitHub 저장소에 파일 올리고 Pages 켜기

## 기능 요약
- 글쓰기: 로그인 없이 바로 게시. 글 번호는 1번부터 자동으로 매겨짐
- 삭제 비밀번호(선택): 정해두면 다른 기기·인앱 브라우저에서도 삭제 가능. 안 정하면 작성한 브라우저에서만 삭제 가능
- 댓글: 글마다 익명 번호(이름1, 이름2…), 글쓴이는 "작성자"로 표시. 댓글은 작성한 브라우저에서만 삭제 가능
- 신고: 1인 1회, **3회 누적 시 자동으로 가려짐** (`app.js`의 `REPORT_LIMIT`와 rules의 `>= 3`을 같이 바꾸면 조정 가능)
- 도배 방지: 글 30초, 댓글 10초 간격 (rules의 `rateOk('lastPost', 30)`, `rateOk('lastComment', 10)`)
- 관리자: 페이지 맨 아래 "관리자" → 비밀번호 입력
  - 모든 글·댓글 삭제 / 가리기 / 가림 해제
  - "가려진 글 보기"로 신고 누적된 글 확인
- 링크 복사: 글 하나를 `#/p/글ID` 주소로 공유 가능
- 테마: 상단 버튼으로 전환, 브라우저에 기억됨 (인앱 브라우저 첫 방문 시엔 기본 테마)

## 익명성 관련
- 글·댓글에는 작성자 ID가 저장되지 않고, `글ID + 사용자ID`를 섞은 해시만 저장됩니다.
  → 같은 글 안에서는 같은 사람으로 묶이지만, **다른 글끼리는 같은 사람인지 알 수 없습니다** (관리자도 마찬가지).
- 삭제 비밀번호도 해시로만 저장되고 관리자 외에는 읽을 수 없습니다.
